# journal-hub-backend

Uma API backend para um sistema simples de banca de jornal. Fornece endpoints REST implementados com Spring Boot para gerenciar revistas, livros e outros produtos com autenticação básica (JWT). Projetado para alimentar um frontend ou app móvel para navegação em um serviço minimalista de banca de jornal.


## Recursos
- Registro e login de usuários (JWT)
- CRUD de produtos (revistas, livros, etc)
- Listagem de categorias e marcação simples (tags)
- Separação simples de papéis (visitante, consumidor, admin)
- Implementado com Spring Boot — leve e fácil de estender

## Visão rápida
Este repositório contém o backend para um sistema simples de banca de jornal — gerenciar conteúdo. Os endpoints REST são implementados usando Spring Boot (Java).

## Tecnologias (exemplo)
- Linguagem: Java (25)
- Framework: Spring Boot (REST, Spring Security, JPA)
- Autenticação: JSON Web Tokens (JWT)
